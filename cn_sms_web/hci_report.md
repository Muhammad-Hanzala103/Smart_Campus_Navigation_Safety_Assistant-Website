# HCI & Usability Report

## Personas

### 1. Admin (Sarah, 45)
- **Role**: Campus Administrator
- **Goal**: Manage campus resources efficiently and ensure safety.
- **Pain Points**: Scheduling conflicts, lack of visibility on maintenance issues.

### 2. Security Officer (Mike, 30)
- **Role**: Head of Security
- **Goal**: Respond to incidents quickly.
- **Needs**: Real-time incident logs and location data.

### 3. Staff Member (Dr. Ali, 50)
- **Role**: Professor
- **Goal**: Book rooms for extra classes without hassle.
- **Frustrations**: Double booked rooms.

## Usability Tasks

1. **Task**: Book a room for a lecture.
   - **Metric**: Time to complete (< 30s).
   - **Success**: Booking shows as "Pending" or "Approved".

2. **Task**: Report a broken window.
   - **Metric**: Ease of finding button (1 click).
   - **Success**: Incident appears in dashboard list.

3. **Task**: Add a new building to the map.
   - **Metric**: Accuracy of placement.
   - **Success**: Node appears on SVG map at correct coords.

4. **Task**: Review daily stats.
   - **Metric**: Legibility of charts.

## Accessibility Checklist
- [x] High contrast colors for text.
- [x] Alt text for critical images (map nodes have titles).
- [x] Keyboard navigation support for forms.
- [x] Clear error messages.

# CIIAS - Admin & Security Manual

## 1. System Overview
The Admin Console provides total situational awareness of the campus. It includes:
- **Map Intelligence:** Real-time view of incidents and shuttles.
- **User Management:** Control roles (Student, Staff, Security).
- **Audit Logs:** Track every action in the system.

## 2. Managing Security Incidents
1.  Navigate to **Dashboard > Incidents**.
2.  **Live Alerts:** High-severity alerts (SOS, Fire) appear instantly.
3.  **Action:** Click "View Details" to see the camera feed (if available) or reporter location.
4.  **Status:** Change status from `Open` -> `In Progress` -> `Resolved`.

## 3. Map Intelligence Pro
- **Layers:** Toggle "Students", "Shuttles", "Heatmap" from the right sidebar.
- **Geofencing:** Draw polygons on the map to define "Safe Zones".

## 4. User Roles
| Role | Permissions |
|------|-------------|
| Admin | Full Access + Settings |
| Security | Incidents + Map + Analytics |
| Staff | Dashboard + Reports |

---
**Troubleshooting:**
If the WebSocket disconnects, refresh the page. The status indicator in the top right should be "green".

## 🚀 Overview

**CIIAS** (Campus Integrated Intelligence & Analytics System) is an enterprise-grade web platform designed to unify **Academic Success**, **Campus Safety**, and **Daily Logistics** into a single, cohesive ecosystem. This web portal serves as the command center for the entire Smart Campus infrastructure.

## ✨ Key Features (Ultimate Edition)

### 🛡️ Command Center & Safety
*   **Live Map Intelligence Pro:** Real-time incident tracking with Heatmaps and Advanced Filtering.
*   **AI Threat Detection:** Automated severity analysis (High/Medium/Low) using LLMs.
*   **SOS Monitoring:** Instant alerts from the mobile app with geo-fencing.

### 🎓 Academic Portal
*   **Live Result Dashboard:** Real-time GPA/CGPA calculation and result visualization.
*   **Digital Attendance:** Smart attendance tracking synced with biometric data.
*   **Faculty Suite:** Course management and student engagement tools.

### 🚌 Smart Logistics
*   **Transport Ops:** Live Shuttle Tracking (GPS) and route management.
*   **Smart Cafeteria:** Digital Menu, Order Queues, and Real-time Kitchen Display System (KDS).
*   **Financial Hub:** Integrated Wallet for cashless campus payments and Fee Challan tracking.

### 💬 Engagement
*   **Campus Chat:** Secure P2P messaging system for students and faculty.
*   **AI Assistant:** 24/7 Chatbot for campus queries.

## 🛠️ Tech Stack

*   **Backend:** Python Flask (Enterprise Pattern)
*   **Database:** PostgreSQL (Production) / SQLite (Dev)
*   **Frontend:** HTML5, Tailwind CSS, Alpine.js
*   **Real-time:** Socket.IO (WebSockets)
*   **Mapping:** Leaflet.js + OpenStreetMap
*   **Deployment:** Docker Ready / Vercel Optimized

## 🚀 Quick Start (Local Dev)

1.  **Clone the Repository:**
    ```bash
    git clone https://github.com/Muhammad-Hanzala103/SSNS-Web.git
    cd SSNS-Web
    ```

2.  **Install Dependencies:**
    ```bash
    pip install -r requirements.txt
    ```

3.  **Run the Server:**
    ```bash
    python wsgi.py
    ```
    Visit `http://localhost:5000` to see the new **Product Showcase Landing Page**.

## ☁️ Deployment (Vercel)

This project is configured for **One-Click Deployment**.
1.  Import repository to Vercel.
2.  Add Environment Variables (`DATABASE_URL`, `SECRET_KEY`).
3.  Deploy.
